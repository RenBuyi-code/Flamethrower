# 回归清单（你驱动 / AI执行）

日期：2026-04-27  
适用版本：当前 `master` 工作树（重构至 Step 22 之后）

## 1. 使用方式

你按顺序驱动测试场景，AI负责：

- 给出每项操作步骤
- 说明预期行为
- 指出关键日志观测点
- 记录通过/失败与备注

建议每项都记录：

- `结果`：`PASS` / `FAIL`
- `现象`
- `日志关键字`

---

## 2. 前置条件

- 固件已编译并烧录成功
- RTT 可正常查看日志
- DMX 控制器可用（支持断开/恢复）
- 压力与倾斜输入具备可控测试条件

---

## 3. 场景清单

### [A] DMX 离线保护

- 步骤：
1. 切到 `USER` 模式并确保系统处于可运行状态
2. 先让 DMX 在线并发送正常帧
3. 断开 DMX 输入（或停止发帧）

- 预期：
1. 系统不继续执行危险动作
2. 触发 `SAFE_OFF` 路径

- 观察点：
- `EVT_DMX_ONLINE_BIT` 清除
- 执行器输出进入安全关闭态

---

### [B] E1 压力建立异常

- 步骤：
1. 在需要建立压力的工况下运行
2. 模拟压力无法达到阈值或压力传感器异常

- 预期：
1. E1 被置位（由 `task_safety` 负责）
2. 系统走安全关闭路径

- 观察点：
- `pressure sensor fault` / fault mask 变化日志
- 故障位包含 `FAULT_E1_PRESSURE_BUILD`

---

### [C] E3 电压异常保持

- 步骤：
1. 让系统进入正常运行
2. 模拟电压超范围并保持超过 `CFG_VOLTAGE_ERROR_HOLD_MS`

- 预期：
1. E3 被置位
2. 恢复正常电压后可按规则清除

- 观察点：
- fault mask 对应 E3 位变化

---

### [D] E5 泄压失败

- 步骤：
1. 触发泄压流程
2. 模拟压力在超时时间内无法降到 `CFG_PRESSURE_RELIEF_DONE_PCT` 以下

- 预期：
1. E5 被置位
2. 系统保持安全策略，不继续危险动作

- 观察点：
- fault mask 对应 E5 位变化

---

### [E] USER / TEST 模式切换

- 步骤：
1. 在 TEST 下验证按键行为
2. 切换到 USER，验证 DMX 驱动行为
3. 多次来回切换

- 预期：
1. 模式切换后状态机过渡正确
2. TEST 下动作优先级与 USER 下策略不串扰

- 观察点：
- 状态迁移日志（`state X -> Y`）
- TEST 动作日志（`test mode action=...`）

---

### [F] SAFE_OFF 抢占

- 步骤：
1. 在可触发动作时（如点火/泵运行）制造安全事件
2. 观察高优先级安全命令是否抢占

- 预期：
1. `SAFE_OFF` 能覆盖当前动作并快速生效
2. 不出现“先继续动作再慢停”的异常

- 观察点：
- 高优先级命令发送路径日志
- 执行器状态快速回到安全关闭

---

### [G] UI 参数保存链路

- 步骤：
1. 在 UI 中修改 `DMX地址/模式/点火延迟/锁阀延迟/倾斜保护/语言`
2. 保存后重启设备

- 预期：
1. 参数通过 `app_fsm_apply_params()` 落地（含 sanitize）
2. 重启后参数保持正确

- 观察点：
- `params applied:` 日志
- UI 读到的参数与保存值一致（或 sanitize 后一致）
