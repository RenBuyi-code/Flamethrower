大喷火机程序要求及控制逻辑及显示

1、芯片型号：雅特力AT32F415CBT7 LQFP48。

2、引脚功能：10脚：压力传感器。11脚：模式转换开关指示灯。12脚：O-LED，暂时不用。13脚：电源开关指示灯。14、15、16脚：分别从3组不同电源分别经过1个100K电阻到CPU，作用不详。17脚：菜单键。18脚：减键。19脚：加键。20脚：确认键。21脚：油泵工作指示灯。22脚：报错指示灯。25脚：油泵驱动。26脚：2号电磁阀，暂时不用。27脚：1号电磁阀，锁油阀。28脚：3号电磁阀，泄压阀。29脚：点火器。31脚：DMX信号输入。33脚：无线遥控信号输入，暂时不用。34、37脚：ISP，烧录脚。38脚：倾斜开关。40脚：LCD SCLK。41脚：LCD-SID。42脚：LCD-CS。43脚：LCD背光。45脚：DMX信号指示灯。46脚：接收信号指示灯，暂时无用。

 

3、菜单显示：每次通电显示  "欢迎使用" 2秒，然后转换为  "系统检测中..."，（检测压力罐油料，机器是否倾斜，泄压是否错误）如果检测压力罐内油料足够就切换到显示"准备就绪"，如果压力不够就马上加压。

再按菜单键显示DMX地址码设置：001-512。-----DMX模式选择2CH/6CH----点火器延时设置0-200mS，----锁油阀延时设置0-200mS（正常情况下这2个是同时工作的）----倾斜传感器设置（是否有作用）默认开有作用。

4、为了安全起见，设备有测试模式和使用模式：接通好电源后，将安全锁置于TEST MODE（测试模式）下，设备测试加压（加压13秒压力达到100%）、泄压、点火是否正常，但燃油喷射功能禁用（锁油阀不工作），不喷出燃油和火焰。此模式可以手动按钮操控，也可以DMX控台做序列测试。

5、使用模式：将安全锁切换到USER MODE，用DMX控台控制。喷火时油泵、锁油阀、点火器都同时工作。

停止喷火时锁油阀、点火器停止工作，而油泵是否继续工作要根据压力传感器的检测结果来判断是否需要继续加压（在喷火工作时压力应该有个范围，低于某个值时才会停止喷火）。启动喷火时油泵马上工作加压。

泄压时只有泄压阀工作。

6、报错信息：E1：升压错误，加压加不上。E2：机器倾斜，机器倾斜大于45度启动报错。E3：电压错误，电池电压大于15V或者低于10V持续5秒钟，机器停止运行。E4:系统已上锁，安全锁置于TEST MODE/测试模式。E5：泄压错误，泄压故障。

7、DMX模式

### 7.1 两通道模式 (2CH)

| 通道 | 功能 | DMX 值 | 功能说明 |
|------|------|--------|----------|
| 通道一 (CH1) | 点火开关 | 0~253 | 不喷火 |
| | | 254~255 | 启动喷火。这个通道上的 DMX 值高于 253 时，喷火机就会点火 |
| 通道二 (CH2) | 模式设置 | 0~49 | 泄压模式（可急停序列） |
| | | 50~200 | 正常喷火模式 |
| | | 201~255 | 泄压模式（可急停序列） |

### 7.2 六通道模式 (6CH)

| 通道 | 功能 | DMX 值 | 功能说明 |
|------|------|--------|----------|
| 通道一 (CH1) | 无 | - | 未使用 |
| 通道二 (CH2) | 无 | - | 未使用 |
| 通道三 (CH3) | 点火开关 | 0~253 | 不喷火 |
| | | 254~255 | 启动喷火。这个通道上的 DMX 值高于 253 时，喷火机就会点火。 |
| 通道四 (CH4) | 点火时间设置 | 0 | 永久喷火 |
| | | 1~254 | 10~2540ms（手动点火时间 = DMX 值 × 10ms） |
| | | 255 | 永久喷火 |
| 通道五 (CH5) | 无 | - | 未使用 |
| 通道六 (CH6) | 模式设置 | 0~49 | 泄压模式（可急停序列） |
| | | 50~200 | 正常喷火模式 |
| | | 201~255 | 泄压模式（可急停序列） |

**注意：** 
- 2 通道模式适合简单控制场景
- 6 通道模式支持点火时间精确控制（10ms 步进，最长 2540ms）
- 两种模式的通道二/通道六功能相同，用于模式切换和急停控制
